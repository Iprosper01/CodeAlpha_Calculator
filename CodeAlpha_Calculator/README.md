# CodeAlpha_Calculator

Basic calculator built for the CodeAlpha Frontend Development internship (Task 2).

## Features
- +, −, ×, ÷, percent, sign toggle, clear
- Full keyboard support (numbers, operators, Enter, Backspace, Escape)
- Live result display

## Run it
Open `index.html` in any browser. Files: `index.html`, `style.css`, `script.js`.

Push this folder to a GitHub repo named `CodeAlpha_Calculator`.
